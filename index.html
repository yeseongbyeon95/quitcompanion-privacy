이 방침은 금연해요의 기기 내 기록, 선택적 백업 및 이메일 문의 처리 방법을 안내합니다.

1. 기기에 저장하는 기록과 이용 목적

금연해요는 금연 기간과 일상 기록을 확인하고 짧은 대처 도구를 이용하는 앱입니다. 금연 시작·재시도 시각, 담뱃값, 금연 이유, 흡연 욕구·흡연 기록, 상황·대처법·메모, 실천 기록과 설정을 기기의 앱 저장소에 보관합니다. 입력한 내용으로 금연 경과와 예상 절약액, 기록 요약을 기기 안에서 계산합니다.

앱은 회원가입이나 자체 서버를 사용하지 않습니다. 운영자가 앱의 개인 기록을 받거나 조회하는 기능은 없습니다. 운영 분석·외부 오류 수집·추적 도구를 사용하지 않으며 실명·이메일·생년월일·주소를 앱 입력 항목으로 요구하지 않습니다. 이 설명은 개인정보 또는 건강 관련 기록이 존재하지 않는다는 뜻이 아닙니다.

2. 보관·보호·삭제

기기의 기록은 사용자가 삭제할 때까지 보관합니다. 개별 기록은 기록 화면에서 수정·삭제할 수 있고, 설정에서 전체 데이터를 삭제할 수 있습니다. 앱 자체의 별도 암호화나 잠금 기능은 제공하지 않으며 운영체제의 앱 저장소 보호를 이용합니다. 기기를 다른 사람이 사용할 수 있다면 기록을 볼 수 있습니다.

앱 저장소의 기록은 운영체제의 자동 클라우드 백업에서 제외하도록 설정합니다. 별도 백업이 없다면 앱 삭제나 기기 변경 시 기록을 잃을 수 있습니다. 전체 삭제 시 앱의 로컬 알림 예약과 위젯 공유 정보도 정리합니다.

3. 선택적 iPhone 파일 백업

iPhone에서 사용자가 백업을 켜고 폴더를 선택하면 기록·메모·금연 이유·설정을 읽을 수 있는 JSON 파일로 저장합니다. 파일 자체에는 별도 암호를 걸지 않습니다. iCloud Drive를 선택하면 Apple이, 다른 파일 제공자를 선택하면 해당 제공자가 전송·보관을 처리합니다. 운영자는 이 파일을 받거나 접근하지 않습니다. 제공자의 처리 국가·보관·전송·복구 정책은 사용자가 선택한 서비스와 계정에 따릅니다.

자동 백업은 앱 사용 중 변경 후와 앱을 다시 열 때 동작합니다. 최근 파일 3개를 기준으로 보관하되 업로드 확인을 위해 더 남을 수 있으며, 다른 설치에서 만든 파일은 자동으로 삭제하지 않습니다. 파일 저장과 클라우드 업로드 완료는 구분해 표시합니다.

백업 연결을 끄거나 기기의 전체 데이터를 삭제해도 이미 저장한 백업은 남습니다. 백업 화면에서 연결 폴더의 앱 백업을 별도로 삭제하거나 파일 앱에서 관리할 수 있습니다. 제공자의 휴지통·복구 사본은 해당 서비스에서 관리해야 합니다. 복원은 확인 후 현재 기기 기록을 교체하며 알림은 OFF로 복원합니다. Android에는 이 파일 백업 기능을 제공하지 않습니다.

4. 위젯·알림·외부 링크

iPhone 홈 화면 위젯은 시작·갱신 시각과 선택 입력한 하루 원화 지출만 기기 안에서 앱과 공유합니다. 메모·이유·상황 태그는 위젯과 공유하지 않습니다. 홈 화면에는 금연 경과나 예상 절약액이 보일 수 있습니다.

일일 알림은 기본 OFF이며 사용자가 켤 때 시스템 권한을 요청합니다. 기기에서 예약한 로컬 알림이고 개인 메모나 건강 상태를 기본 알림 문구에 넣지 않습니다. 사용자가 공식 지원기관 등의 링크를 누르면 운영체제의 브라우저나 연결 앱으로 열리며, 이후 처리는 해당 외부 서비스의 정책을 따릅니다.

5. 광고와 외부 SDK

첫 배포 버전에서는 운영 광고를 제공하지 않습니다. 배포 모드에서는 앱의 광고 SDK 초기화·배너 요청을 차단합니다. Google Mobile Ads SDK가 앱 바이너리에 포함된 사실과 광고 요청을 실행하는 것은 구분합니다. 개발용 공식 테스트 광고는 명시적으로 켠 개발 빌드에서만 사용하며 Google과 외부 통신이 발생할 수 있습니다.

금연 날짜·지출·흡연 욕구·흡연 이력·상황·이유·자유 메모를 광고 요청이나 타기팅에 전달하지 않습니다. 운영 광고를 도입할 때에는 처리 항목·제공자·필요한 동의·철회 방법을 다시 검토하고 정책을 갱신합니다.

6. 이메일 문의와 권리 행사

사용자가 contact2ysb@gmail.com으로 문의하면 운영자가 회신 주소와 문의 내용을 받아 문의 처리에 사용합니다. 금연 기록·메모·인증정보를 이메일에 첨부할 필요는 없습니다. 앱에 저장한 기록은 운영자가 원격으로 조회·수정·복원할 수 없으므로 앱의 편집·삭제·백업 관리 기능을 이용해 주세요.

문의 이메일은 처리 완료 후 30일 이내 삭제하고, 법령상 보존 의무가 있는 경우에만 해당 기간 보관합니다.

7. 공개 안내 페이지와 변경

정책·지원 페이지는 GitHub Pages에 게시하며, 페이지 접속 정보는 GitHub의 웹 호스팅 정책에 따라 처리될 수 있습니다. 앱의 금연 기록을 이 페이지에 전달하지 않습니다. 공개 페이지에는 외부 분석·광고·원격 폰트를 넣지 않습니다. GitHub 개인정보처리방침을 참고할 수 있습니다.

처리 방식이 바뀌면 정책의 시행일과 변경 내용을 갱신합니다. 문의 담당자는 운영자 Yeseong Byeon이며 연락처는 contact2ysb@gmail.com입니다.
